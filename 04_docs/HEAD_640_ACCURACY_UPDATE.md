## 结果

相同 QAT INT8 权重，比较置信度固定 0.3、NMS 从 0.45 改为 0.35：

| 数据 | 旧平均人数误差 | 新平均人数误差 |
|---|---:|---:|
| 验证集 861 张 | 3.3844 | 2.2323 |
| 独立测试集 1000 张 | 3.6020 | 2.3720 |
| 验证集 >=50 人的 186 张 | 7.3172 | 4.8333 |
| 测试集 >=50 人的 225 张 | 7.8444 | 5.1156 |

测试集 precision 74.99% → 81.61%，recall 83.92% → 83.27%；人数统计改善，但有轻微召回代价。
AP50 0.82704 → 0.82510，略降，所以不能称所有检测指标都改善。
原摄像头配置置信度为 0.2；修正至 0.3 后进一步减少低置信度误检。

评估目录：`outputs/head_training/eval_qat640_nms035_val_v1` 和 `eval_qat640_nms035_test_v1`。
全部统计基于量化模型在电脑运行，不是 FPGA 对全部数据集的准确率认证。

## 使用

关闭正在运行的检测窗口后重新运行原命令，新默认值自动生效，无需另行手动烧录。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\codex\2026-09-27\yong\scripts\run_head_detection.ps1" -InputSize 640 -SpeedCandidate -Source 0
```

脚本默认仍会重新烧录并上传权重。如果开发板确实保持当前提速候选及 DDR 权重，可加 `-ReuseLoadedBoard` 跳过该步骤。
可用 `-Confidence 0.3 -NmsIou 0.35` 显式指定。
回到旧后处理配置可用 `-Confidence 0.2 -NmsIou 0.45`。

仍需改进小人头漏检、密集重叠人头及真实摄像头域差异。下一阶段可做 640 分辨率微调并以同一固定测试协议验收；本轮没有启动训练，也没有宣称消除所有误检。
